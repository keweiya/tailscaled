Exemptions are the three RETURN rules that keep tunnel traffic out of a proxy's interception (pre = mangle PREROUTING, out = mangle OUTPUT, nat = nat OUTPUT). All three must read OK.

Routed prefixes

Destinations listed here are sent into the tunnel. One prefix per line, # starts a comment. Add a peer's advertised subnet (for example 192.168.100.0/24) to reach its LAN from any browser.

Remember that tailscale set --accept-routes must also be on, otherwise tailscaled drops the packets it receives for those subnets.

Discovered subnets

Reads the subnet routes the control plane says are reachable (Peer.PrimaryRoutes), writes them to routes.auto and installs them. This file is regenerated automatically, so your own entries in routes are never touched. Requires Accept subnet routes to be on.

Not available in this build
  • Use an exit node — impossible here. A GOOS=android tailscaled cannot mark its own sockets, so routing 0.0.0.0/0 into the tunnel would send the daemon's own packets back into its own tunnel and stall it. The module refuses this on purpose.
  • Tailscale SSH — built with ts_omit_ssh: feature/ssh excludes android while cmd/tailscaled/ssh.go does not, so it cannot be linked.
  • Automatic updates — forced off. An upstream update installs the linux build, which blocks the link; the binary guard reverts it.
